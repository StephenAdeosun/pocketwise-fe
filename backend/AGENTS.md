# Backend Instructions

Read `../docs/SRS.md`, `../docs/API_CONTRACT.md`, and `../docs/FRONTEND_CONTEXT.md` before editing backend code.

Keep the backend organized into `app/models`, `app/schemas`, `app/routers`, `app/services`, and `app/security`. Keep API amounts as decimal strings and scope all protected data by the authenticated user.

Run the backend tests and the application startup check after changes.
